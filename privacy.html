Privacy Policy

अंतिम अपडेट: 21 सितम्बर 2026

1. Local editing

Manual Poster और Cartoon Video editing browser में होती है। Local gallery, autosave और Assets Library का data आपके browser storage में रखा जाता है। Browser data साफ करने पर यह हट सकता है।

2. Upload की गई files

Manual editor में चुनी photos, logos, audio और backup files processing के लिए browser में पढ़ी जाती हैं। महत्वपूर्ण original files और JSON backup अलग सुरक्षित रखें।

3. AI सुविधा

AI सुझाव का उपयोग करने पर आपके द्वारा लिखी product/category/brand जानकारी configured Cloudflare Worker को भेजी जा सकती है। Password, payment card, पहचान-पत्र या संवेदनशील व्यक्तिगत जानकारी prompt में न लिखें।

4. Login और payment

वर्तमान local editor verified email account, cloud sync या paid subscription उपलब्ध होने का दावा नहीं करता। ऐसी सुविधा शुरू होने पर यह policy अपडेट की जाएगी।

5. User control

आप Gallery से projects हटा सकते हैं और browser settings से इस site का local storage साफ कर सकते हैं। Data हटाने से पहले JSON backup लें।

6. संपर्क

Privacy या सुरक्षा समस्या के लिए APANAM के आधिकारिक संपर्क माध्यम का उपयोग करें।
