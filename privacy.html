Privacy Policy

अंतिम अपडेट: 6 अक्टूबर 2026

1. Local editing

Manual Poster और Cartoon Video editing browser में होती है। Local gallery, autosave और Assets Library का data आपके browser storage में रखा जाता है। Browser data साफ करने पर यह हट सकता है।

2. Upload की गई files

Manual editor में चुनी photos, logos, audio और backup files processing के लिए browser में पढ़ी जाती हैं। महत्वपूर्ण original files और JSON backup अलग सुरक्षित रखें।

3. AI सुविधा

AI सुझाव का उपयोग करने पर आपके द्वारा लिखी product/category/brand जानकारी configured Cloudflare Worker को भेजी जा सकती है। Password, payment card, पहचान-पत्र या संवेदनशील व्यक्तिगत जानकारी prompt में न लिखें।

4. Login, profile और cloud backup

Login और email verification Supabase से जुड़े हैं। अपने profile में नाम, email, mobile/WhatsApp, संस्था, शहर, website और photo रख सकते हैं। अधिकृत admin user directory और membership विवरण देख सकता है। Mobile/WhatsApp के भरे हुए नंबर अपने-आप verified नहीं होते। Cloud backup और Cloud Files चुनने पर file आपके account के निजी cloud storage में भेजी जाती है। प्रकाशित admin templates सभी users को दिखते हैं।

5. Trial और reminders

₹10 registration के बाद पहली 15 दिन की अवधि की तारीख server पर रखी जाती है। ₹100 हर 30 दिन AutoPay के लिए अलग स्पष्ट सहमति और बैंक mandate जरूरी है। Expiry Email reminder के लिए अलग सहमति दें या Membership page से वापस लें। Configured provider चालू होने पर expiry सूचना भेजने के लिए verified email provider तक जाएगी। Reminder queue का पूरा हुआ इतिहास लगभग 90 दिन बाद साफ किया जाता है। Automatic SMS/WhatsApp अभी सक्रिय नहीं है।

6. Payment और AI लागत

Membership payment Cashfree checkout से लिया जा सकता है। Order, राशि, payment status और membership की अवधि server पर रखी जाती है। Email provider और sender/scheduler सक्रिय होने पर सफल payment की admin Email सूचना भेजी जा सकती है। Card/UPI checkout provider संभालता है। Paid AI credits और generation अभी बंद हैं; AI लागत estimates कोई charge नहीं करते। Image selection/OCR/repair के स्थानीय models पहली बार Internet से डाउनलोड होते हैं; इन स्थानीय tools में image browser में process होती है। AI पीछे छिपी असली चीज वापस मिलने की गारंटी नहीं देता।

7. User control

आप Gallery से projects हटा सकते हैं और browser settings से इस site का local storage साफ कर सकते हैं। Cloud Files से अपनी files हटा सकते हैं; ready file हटाने से पहले local download दिया जाता है। Trial की तारीख browser data साफ करने से reset नहीं होती। Data हटाने से पहले JSON backup लें।

Account और उससे जुड़े data को हटाने की request Membership में दें या registered email से सहायता लें। AutoPay और balance का निपटारा अलग जाँचा जाएगा; आवश्यक retained records का कारण परिणाम में दिया जाएगा।

8. सहायता और error diagnostics

App सहायता shortcuts स्थानीय guide से जवाब देते हैं; सामान्य AI Chat Sarvam से जवाब देता है। बातचीत स्थायी browser storage में नहीं रखी जाती। AI Chat में स्पष्ट अनुमति पर सवाल और हाल की सीमित बातचीत Sarvam को भेजी जाती है; bank/account निजी स्थिति chat को उपलब्ध नहीं है। Provider आवाज़ में बोलने वाला text भी Sarvam को भेजा जाता है। Password, OTP, card या API keys न लिखें। Signed-in app errors में केवल account ID, सेवा/category, error code और समय server पर रखे जाते हैं; raw message, prompt या payment विवरण नहीं। Diagnostic/request-counter records 30 दिन से पुराने होने पर अगली report/request में हटते हैं। अधिकृत admin को aggregated error counts दिखते हैं।
