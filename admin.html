Cloud Admin · Login और Publish

Login करने से अपने-आप admin अधिकार नहीं मिलता। केवल अधिकृत owner cloud draft और public posters बदल सकता है।

पहले local backup लें। Publish में केवल visible templates जाते हैं। हर image अधिकतम 2 MB रखें; project और storage quotas लागू हैं।

Users / Profiles

नाम, email, संस्था, mobile या WhatsApp से user खोजें। Mobile/WhatsApp user द्वारा भरे गए हैं। Reminder से तैयार संदेश खुलेगा; भेजना आपको होगा। Automatic SMS/email अभी चालू नहीं है।

अधिकृत Admin login करके सूची खोलें।

Business users · मुफ्त Manual Access

User अपने Membership page से User ID साझा करे। यह केवल manual membership का रिकॉर्ड है; AI credits या admin अधिकार नहीं देता। नए grant से पुरानी समाप्ति तारीख बदल जाएगी।

App / Website Settings

इन switches से public interface बदलता है। Cloud publication के लिए अधिकृत admin login जरूरी है।

Posters / Templates जोड़ें

कई PNG/JPG/WebP/GIF या editable JSON एक साथ चुनें। अवसर और तारीख लगाने से user “आज के posters” में उन्हें पा सकेगा। चंद्र कैलेंडर वाले त्योहार की तारीख हर साल सही करें; हर साल विकल्प केवल स्थिर तारीख वाले अवसर के लिए है। कोई तय template संख्या नहीं है; उपलब्ध browser storage और hosting/file limits लागू हैं। बड़े संग्रह को छोटे catalog packs में backup रखें।

नया editable poster बनाएँ → Save JSON

Publish / Backup

  1. Templates और settings का draft यहाँ सेव करें।
  2. Catalog JSON डाउनलोड दबाएँ। फ़ाइल का नाम studio-catalog.json रखें।
  3. Cloud Admin में login करके सभी users के लिए Publish दबाएँ।
  4. Users app refresh करके नए posters देखें। GitHub में catalog upload पुराना backup/fallback विकल्प है।
GitHub में प्रकाशित करें ↗Deployment स्थिति ↗

Browser data साफ करने से draft मिट सकता है। नियमित catalog backup रखें। Draft में बदलाव live catalog को अपने-आप नहीं बदलता।

पूरे Software / Website का नियंत्रण

Templates, नाम, सूचना और editor switches ऊपर से संभालें। नए features, code, layout और software सुधार के लिए इसी GitHub repository में बदलाव करें। GitHub का owner/maintainer ही live source प्रकाशित कर सकता है।
