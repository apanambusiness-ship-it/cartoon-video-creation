यह workspace इस browser में draft बनाता है। सभी users के लिए catalog/settings प्रकाशित करने के लिए GitHub में अधिकृत owner account जरूरी है। इस public page को खोलने से किसी को आपकी live website बदलने का अधिकार नहीं मिलता।

App / Website Settings

इन switches से public interface बदलता है। GitHub publication का अधिकार GitHub खाते से तय होता है।

Posters / Templates जोड़ें

कई PNG/JPG/WebP/GIF या editable JSON एक साथ चुनें। कोई तय template संख्या नहीं है; उपलब्ध browser storage और hosting/file limits लागू हैं। बड़े संग्रह को छोटे catalog packs में backup रखें।

नया editable poster बनाएँ → Save JSON

Publish / Backup

  1. Templates और settings का draft यहाँ सेव करें।
  2. Catalog JSON डाउनलोड दबाएँ। फ़ाइल का नाम studio-catalog.json रखें।
  3. GitHub में प्रकाशित करें खोलें, इसी फ़ाइल को upload/replace करें और commit करें। GitHub owner login जरूरी है।
  4. GitHub Pages deployment हरा होने के बाद app refresh करें।
GitHub में प्रकाशित करें ↗Deployment स्थिति ↗

Browser data साफ करने से draft मिट सकता है। नियमित catalog backup रखें। Draft में बदलाव live catalog को अपने-आप नहीं बदलता।

पूरे Software / Website का नियंत्रण

Templates, नाम, सूचना और editor switches ऊपर से संभालें। नए features, code, layout और software सुधार के लिए इसी GitHub repository में बदलाव करें। GitHub का owner/maintainer ही live source प्रकाशित कर सकता है।

Software source / सभी files ↗बदलाव का इतिहास ↗Admin guide

इस व्यवस्था में Vercel, भुगतान या browser में GitHub token डालने की जरूरत नहीं है। AI, email login और cloud sync अलग server setup के बिना सक्रिय नहीं दिखाए जाएँगे।
